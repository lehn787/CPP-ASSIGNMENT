# Student Marks Analyzer

A simple C++ program that stores student marks and generates a report showing:

- Total marks
- Average marks
- Highest mark
- Lowest mark
- Number of passed students
- Number of failed students

## Features

- Input validation (1-100 students)
- Array-based mark storage
- Pass/fail calculation
- Average calculation
- Highest and lowest mark detection

## Example

### Input

```text
Enter number of students: 3
Enter mark for student 1: 80
Enter mark for student 2: 35
Enter mark for student 3: 65
```

### Output

```text
----- REPORT -----
Total Marks : 180
Average     : 60
Highest Mark: 80
Lowest Mark : 35
Passed      : 2
Failed      : 1
```

## How to Compile

```bash
g++ STUDMARKANALYZER.cpp -o analyzer
```

## How to Run

```bash
./analyzer
```
